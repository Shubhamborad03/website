Setup guide · Google Maps API

Set up Google Maps API for Wolf AI.

A 15-minute walkthrough. Your friend creates the project once, adds Shubham as a developer, and the team is ready to build. Free $200/month credit covers normal usage.

Part 01 ~10 min · one-time

Your friend's setup

Done once on their Google account. Their credit card stays on the billing account.

1
Sign in to Google Cloud Console
Open console.cloud.google.com and sign in with the Google account that will own the project.
2
Create a new project
Top of the screen, click the project dropdown → New Project → name it Wolf AI Maps → Create.
3
Switch to the new project
Wait 30 seconds for it to spin up. Then make sure the project dropdown at the top shows Wolf AI Maps.
4
Add billing
Open the hamburger menu ☰ → Billing → Link a billing account. Add a credit card. Google gives a $200/month free Maps credit forever, so normal usage won't be charged.
5
Enable the Maps APIs
Left menu → APIs & Services → Library. Search for each of these and tap Enable:
Maps Static API — satellite tiles for roof scans
Geocoding API — turns addresses into coordinates
Maps JavaScript API — interactive maps (optional, useful later)
6
Create the API key
Left menu → APIs & Services → Credentials → + Create Credentials at the top → API key. A box pops up with the key. Copy it somewhere safe.
7
Restrict the key (recommended)
On the same Credentials page, click the key name to edit it.
Under API restrictions → select Restrict key → tick the three APIs from step 5.
Under Application restrictions → leave as None for now while testing. Tighten later to HTTP referrers with wolf-ai.com.au/* when ready for production.
Hit Save.
Friend's setup is complete. The key is now usable.
Part 02 ~2 min

Friend adds Shubham as a developer

Gives Shubham access so he can manage the API key and use it for the build.

1
Open IAM
Left menu → IAM & Admin → IAM.
2
Grant access
Click + Grant Access at the top of the page.
3
Add Shubham's email
In the New principals field, type Shubham's Google email.
4
Select the Editor role
In the Select a role dropdown, choose Editor. This lets Shubham manage the API key, see billing, and use everything.
5
Save
Click Save. Shubham will get an email invite. He accepts it and he's in.
Part 03 ~1 min

Shubham's steps

Once Shubham accepts the invite, he can grab the key and start using it.

1
Open the console
Go to console.cloud.google.com.
2
Switch to the project
Top of the screen, click the project dropdown and select Wolf AI Maps.
3
Grab the key
APIs & Services → Credentials → click the API key → copy the key string.
4
Test it works
Paste this in a browser, replacing YOUR_KEY with the key. A satellite image of Brisbane should appear.
https://maps.googleapis.com/maps/api/staticmap?center=Brisbane&zoom=15&size=600x400&maptype=satellite&key=YOUR_KEY
Faster alternative

Don't need full developer access? Skip Part 2.

If Shubham only needs to use the key (not manage the project), Part 2 isn't required. The friend can just send the key string by Signal, Slack, or email. Shubham pastes it into the code and it works. Friend still owns the billing.

Part 2 is only needed if Shubham will:

  • Enable more APIs later
  • See usage and cost in the dashboard
  • Rotate or replace the key himself
